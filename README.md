# Proyecto Urban Grocers

## Descripción

Este proyecto contiene pruebas automatizadas para la API de Urban Grocers.

Se validan 9 casos de prueba para el parámetro `name` en la creación de kits de productos.

## Fuente de documentación

La documentación utilizada fue la documentación de la API de Urban Grocers proporcionada por TripleTen (apiDoc).

## Tecnologías utilizadas

* Python 3
* Pytest
* Requests

## Técnicas de prueba utilizadas

* Clases de equivalencia
* Valores límite
* Pruebas positivas
* Pruebas negativas
